# Service Centre Automation System

Веб-сервис и мобильная часть для автоматизации обработки заявок сервисного центра.

Проект разрабатывался в рамках дипломной работы и преддипломной практики в ООО «Дико Плюс». Основная цель — уменьшить ручную обработку заявок, повысить прозрачность выполнения заказов и улучшить коммуникацию между отделами.

## Основные возможности

* регистрация и авторизация пользователей;
* роли пользователей и разграничение доступа;
* создание и обработка заявок;
* изменение статусов заказов;
* личные кабинеты пользователей;
* уведомления для сотрудников;
* отчеты по заявкам и выполненным работам;
* интеграция с 1С для синхронизации данных;
* мобильная часть для работы с заявками;
* система межотдельной коммуникации.

## Результат

После внедрения решения время обработки заявки уменьшилось на 25%.
Проект был запущен в тестовую эксплуатацию и использовался как инструмент для автоматизации внутренних процессов предприятия.

## Установка и запуск

1. Клонировать репозиторий:

```bash
git clone https://github.com/MishNick/service_centre.git
cd service_centre
```

2. Создать виртуальное окружение:

```bash
python -m venv venv
```

3. Активировать виртуальное окружение:

Для Windows:

```bash
venv\Scripts\activate
```

Для Linux/macOS:

```bash
source venv/bin/activate
```

4. Установить зависимости:

```bash
pip install -r requirements.txt
```

5. Создать файл `.env` на основе `.env.example` и заполнить локальные настройки:

```bash
copy .env.example .env
```

6. Запустить проект:

```bash
python app.py
```
